# Backlink outreach — templates

rust.casino has **zero legitimate backlinks** (Ahrefs, Sep 2026: DR 0, 373 referring
domains, all spam/link farms, 1 dofollow from a DR-0 site). Real links are the only
lever that builds trust on this domain. Target: **5–10 genuine links in 60 days.**

Priority order (fastest → slowest):

1. **Operator partner links** — we already review RustClash, RustyLoot, BanditCamp,
   RustMagic, RustyPot. Affiliates routinely get a "reviewed by / as featured on"
   link. Highest odds, zero cost.
2. **Gaming / crypto / Rust-community blogs** — guest posts on the topics we already
   own (provably fair, KYC, skins economy). Offer the piece, ask for one link.
3. **Rust community resources** — server-list sites, Discord/Reddit wiki-style
   resources that list tools/guides. Genuine presence, not drive-by spam.
4. **Mentions / HARO-style** — answer journalist/blogger requests about skin
   gambling, loot boxes, esports betting; get cited.

Do NOT buy links. The domain is already burned by paid/spam links — more of the
same is the one thing guaranteed to make it worse.
